# Homebrew tap for Weekmark

[Weekmark](https://rockykusuma.github.io/weekmark/) keeps the calendar week on your Mac desktop and answers "when is CW46?" from any app.

```bash
brew install --cask rockykusuma/weekmark/weekmark
```

Weekmark updates itself through Sparkle, so `brew upgrade` isn't needed (the cask sets `auto_updates true`).

Source: [rockykusuma/weekmark](https://github.com/rockykusuma/weekmark)
